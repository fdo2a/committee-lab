# 하나의 롱·숏 모의계좌

사용자 요청: 기존 3국·6부서·6시간 자동 운용에서 하나의 계좌가 서로 다른 종목의 롱과 숏을 동시에 보유한다. 실제 주문과 유료 API는 사용하지 않는다.

기존 스크리닝·바텀업 검증은 조사 대상의 품질을 확인한다. 국가별 하락 국면에서 해당 기업의 하락 추세를 숏으로 헤지한다. 단순한 펀더멘탈 탈락이나 미확인 자료를 공매도 근거로 사용하지 않는다. 상승·횡보 전략은 롱, 하락 전략 20개는 숏 신호로 바꾸고 새 전략 ID를 부여한다. 기존 60개 조합의 시간 순서 검증과 다음 가격 체결 원칙을 유지한다.

숏은 매도대금을 현금에 더하고 현재 상환 의무를 순자산에서 차감한다. 매도대금 또는 현재 상환 의무 중 큰 금액과 현재 숏 평가금액의 100% 추가 증거금은 투자 가능 현금에서 제외한다. 연 3% 대차료를 경과 시간에 비례해 반영한다. 실제 대차 가능·수수료·규제를 조회하지 않는 연구 모델이며 대차 가능을 가정한다. 배당 보전, 리콜, 국가별 공매도 제한과 실제 증거금 규정은 재현하지 않는다.

총노출 100%, 숏 총노출 30%, 절대 순노출 80%, 롱 종목 20%, 숏 종목 10%, 업종 총노출 40%, 신규 계획 손절 손실 0.8%, 합산 손절 손실 2%, 최대낙폭 10%를 제한한다. 승인된 미체결 진입도 한도를 예약한다. 동일 종목 양방향 포지션은 만들지 않는다. 청산은 새 가격이 있을 때만 실행하고 갭에서는 관측한 가격을 사용한다. 숏 가격 급등으로 증거금이 부족하면 우선 상환하며 파산을 손실 한도로 잘라 숨기지 않는다.

구현 순서: DART 요청 헤더 및 리다이렉트 회귀 테스트 → 롱·숏 회계/위험/비용 → 숏 신호·검증·체결·손절·청산 → 서버 복기/컨텍스트 → UI와 방법론 → 전체 테스트·빌드·비공개 게시·실제 DART 및 서버 계좌 조회. 기존 계좌 기록과 6시간 예약을 보존한다.

검증: 혼합 포지션의 순자산·총/순노출, 매도대금 재사용 금지, 숏 이익/손실·불리한 갭·대차료·증거금 상환, 같은 가격 중복 체결 금지, 양방향 청산 복기, 저장/복원, 하락 데이터 숏 검증, 기존 롱 회귀 테스트, 생산 서버 DART 정상 응답과 제공기관 연결 상태.

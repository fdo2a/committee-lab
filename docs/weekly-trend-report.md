# Trend Unit 주간 운용보고서

2026-10-08. 기존 주간 보고서 API·저장·화면을 확장했다. 외부 예약의 저장된 프롬프트와 운영 사이트는 이번 로컬 변경으로 수정되지 않는다.

## 작성 순서

1. Macro Top-down: 지역별 경기·선행지표·물가·정책·유동성을 근거와 관측일로 설명하고 시장 국면·주식/현금 배분에 연결한다.
2. Universe: 매크로 판단이 어떤 산업·스타일로 이어졌는지, 왜 해당 참조지수·후보군을 선택했는지 기록한다. 아이디어의 `universeReason`에 원인을 명시한다. 지수 이름은 이유를 대신하지 않는다.
3. 종목 선정: 같은 Universe의 후보들을 비교하고 최종·예비·제외 이유를 기업 검토·기술 검토·계량 순위와 연결한다. 아이디어 내부 순위를 전체 시장 순위로 쓰지 않는다.
4. 운용·위험: 유닛 구성비, 계좌 예산 상한, 목표·손절·절반 축소·1~3개월 기한을 기록한다. 실제 승인·체결·보류·청산을 구분하고 종료 유닛 성과를 복기한다.
5. 다음 주: 촉매·확인 일정·반증 조건과 유지·진입·교체·현금 대기 조건을 제시한다.

`GET /api/weekly-report-context`의 `writingGuide`를 항목별 작성 규칙으로 사용한다. 기존 네 가지 본문 필드와 HTTPS 출처 입력 형식은 유지한다. `POST /api/weekly-reports`는 본문과 함께 서버가 계산한 해당 주의 `strategyReview`를 저장한다. 작성자가 외부 팩터 점수나 과거 수치를 제출하지 않는다.

## 표시 수치

- Value: 수집 가격 기준 연간 PER와 내부 0~100점.
- Size: 날짜·출처가 있는 시가총액 관측이 있는 종목은 통화와 함께 표시한다. 그 외 미수집이다. Size 점수는 계산하지 않는다.
- Quality: 연간 ROE와 내부 0~100점.
- Dividend: 배당수익률·배당 점수는 현재 미수집으로 표시한다.
- Growth: 연간 전년 대비 매출성장률과 내부 0~100점. EPS 전망 수정치는 미수집이다.
- Momentum: 20거래일 가격 변화와 방향별 기술 점수를 구분한다. 숏 점수는 반대 방향이므로 양의 가격 수익률과 같은 뜻이 아니다.
- 변동성: 최대 최근252개 일간 수익률, 최소60개 관측의 연율 변동성.
- VaR: 과거 중첩60거래일 손실의90%·95% 분위수. 최소120개 중첩 구간이 필요하다. 독립 표본·미래 최대손실 보장이 아니며 개별 값의 가중평균은 바스켓 VaR가 아니다.

수집일·회계기간 말·가격 시점을 함께 표시한다. 가격 위험값은 고정 환율 변환 기준으로 역사적 환율 변동을 반영하지 않는다. 계량 검증 완료는 필수4개 팩터·서버 숫자 검증·30일 이내 재무 수집을 모두 통과해야 한다. 이 점수는 MSCI 공식 방법론이 아니다.

## 과거 자료의 경계

자동 운용 실행은 `summary.strategySnapshot`에 당시 판단·후보별 수치·유닛 조건을 복사해 저장한다. 주간 보고서는 해당 주 실행 로그를 날짜 범위로 조회하며 최근100개로 제한하지 않는다. 월요일00:00 KST부터 토요일09:00 KST까지의 기록을 사용하며 금요일 미국 마감 기록을 포함한다.

주중 종료·제외된 아이디어도 남기고 아이디어별 마지막 관측 시점을 표시한다. 현재 계좌 조회가 과거 보고서의 팩터 수치를 바꾸지 않는다. 기록 도입 전 보고서는 '당시 전략 기록 없음', Universe 선택 이유가 없으면 '당시 미기록'으로 표시한다. 미래 시점의 조사·재무·지수 기록을 과거 근거로 사용하지 않는다.

컨텍스트의 `holdings`, `bonds`, `plans`, `marketReports`, `research`는 조회 시점 자료다. 다음 주 계획의 참고자료로만 사용하며 과거 주간 설명은 `strategyReview`와 해당 주 `runs`를 사용한다. 기존 보고서의 주차별 중복 방지, 계좌 성과·체결·비용 계산은 유지한다.

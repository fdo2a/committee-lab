# Committee Lab MCP

기존 비공개 Site의 `/mcp`에 연결하는 선택 기능입니다. 수집이나 자동 운용에 필수가 아니며, AI와의 대화에서 자료 조회와 조사 점검을 요청할 때 사용합니다. MCP 자체가 제공기관의 자료 품질·응답 속도·호출 제한을 개선하지 않습니다.

## 구현

공식 MCP TypeScript SDK의 stateless Streamable HTTP를 기존 Worker에 연결합니다. 별도 서버·DB·로컬 MCP 설치는 필요하지 않습니다. 세션을 저장하지 않고 요청마다 서버를 생성합니다. 출력은 JSON이며 도구를 사용한 요청이 계좌·조사·거래·일정을 저장하지 않습니다. 빈 계좌에서도 시연 계좌를 생성하지 않습니다.

Site dispatch의 기존 소유자 전용 접근을 유지합니다. 초기화·도구 설명에는 개인 자료가 없으며 실제 도구 호출은 dispatch가 제공한 `oai-authenticated-user-id`가 필요합니다. 서비스 토큰은 사용자 신원으로 대체하지 않습니다. MCP에 임의 URL 입력·API 키 입력·주문·계좌 변경 도구는 없습니다.

## 도구

- `get_investment_context`: 관찰 종목, 운용 상태, 위험 한도, 조사 절차. 이전 부서 의견은 독립 조사를 위해 기본 제외하며 `includeReviews: true`로 요청할 수 있습니다.
- `get_market_data`: 저장된 Python 가격·환율. `symbols`는 관찰 종목 중 최대 40개, `historyBars`는 기본 0·최대 260개입니다. 수집 시점과 실제 가격 관측 시각을 별도로 반환합니다. 시연 가격과 수집하지 않은 종목의 자료는 반환하지 않습니다.
- `get_fundamentals`: 저장된 연간 재무·출처·검증. `storedPass`는 당시 판정이고 `pass`는 자료·사업 조사·가격의 신선도를 다시 확인한 보수적 연구용 판정입니다. 매매 승인이 아닙니다.
- `get_research_data`: DART·EDINET·FRED 중 필요한 기관만 실시간 조회. 공시 반환은 기본 20·최대 100건, 시계열별 관측값은 기본 6·최대 24개입니다. 기존 수집 범위 내에서 응답을 줄이며 누락·잘림·출처·조회 시각을 유지합니다.
- `collect_us_research`: 미국 등록 종목 1~5개의 SEC 공시 메타데이터와 원문 링크를 수집합니다. `query`는 영문 1~500자, `useJev`는 기본 false입니다. true로 명시하면 유료 JEV가 읽기 순서를 제안합니다. 후보를 삭제하지 않으며 원문 내용·수익률·매매 승인 판단을 대신하지 않습니다.
- `evaluate_us_candidates`: 미국 컨셉의 원본 후보 전체를 `discovery` 또는 `admission` 단계에서 비교합니다. `useJev:false` 기본값은 호출·저장을 하지 않습니다. true는 유료 평가 후 metadata에 결과를 기록하므로 read-only 도구가 아닙니다. 계좌의 종목·비중·현금·주문·승인 시각은 변경하지 않습니다. [영문 packet·두 단계 계약](jev-pilot.md)을 따르며 과거 비교는 `replay:true`로 표시합니다.
- `get_jev_evaluations`: 최근20개 평가 기록·원본 근거·항목별 점수·확신·누락·기존 선정과의 차이·토큰 수를 조회합니다. 선정 일치도가 수익 정확도를 의미하지 않습니다.
- `list_companies`: 허용 지수 후보의 국가·이름·종목 기호 검색. 페이지 기본 20·최대 100개이며 `nextOffset`으로 다음 페이지를 조회합니다. 허용 후보와 실제 관찰·조사한 종목은 다릅니다.
- `check_research`: 기존 부서별 조사·매크로·바스켓·출처 검증. `research` 생략 시 저장된 자료를 점검하며 자료를 저장하지 않습니다.

가격은 수집 30분, 연간 재무는 수집 30일(연간 재무는 주 1회 재조회하며 수집 경과만으로 보류하지 않음), 사업 조사는 36시간 기준을 따릅니다. 가격의 `freshness: fresh`는 최근에 조회했다는 뜻으로, 실시간 가격이나 거래 가능한 정규장이라는 뜻이 아닙니다. 수집 시각이 없는 과거 재무는 `unknown`, 미래 수집 시각은 `invalid`로 표시하며 통과로 간주하지 않습니다. 갱신은 기존 Python 수집 절차에서 수행합니다.

DART는 최근 7일 첫 100건, EDINET은 최근 7일 중 최신 제출일의 최대 300건을 수집하며 MCP 반환 한도를 추가 적용합니다. 공시 목록은 공시 원문 재무 검토를 대체하지 않습니다. FRED의 관측일과 조회일은 다르고 값은 개정될 수 있습니다. 오류를 임의 자료로 대체하지 않습니다.

## 배포와 연결

`.openai/hosting.json`에 `mcp` 기능 선언을 추가한 소스를 기존 Site에 배포해야 원격 MCP가 활성화됩니다. 로컬 코드 구현과 테스트 완료만으로 배포·플러그인 연결이 완료된 것은 아닙니다.

배포 후 Sites `get_site(include_mcp_connection: true)`가 반환하는 기존 Site 플러그인을 설치·연결합니다. 별도 앱이나 인증 흐름을 생성하지 않습니다. 연결 후 읽기 도구로 확인합니다. 기존 4시간 자동화의 실행 경로는 API·Python 수집기를 유지하며, MCP를 추가했다고 자동화가 이를 사용하는 것은 아닙니다.

## 확인

`npm run review:code`로 전체 테스트·Python·구문 검사와 Claude 검토를 통과한 소스만 빌드합니다. `tests/mcp.test.mjs`는 공식 MCP 클라이언트 초기화·도구 발견, 인증·Origin 경계, 입력 제한, SQLite 계좌 보존, 시연 자료 차단, 자료 신선도, 기관별 조회·응답 범위와 두 단계 JEV 비교·중복 결제 방지·실패 보존을 검사합니다.
